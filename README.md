# 🛍️ Customer Shopping Behavior Analysis

## 📌 Project Overview
This project focuses on analyzing customer shopping behavior using transactional data from 3,900 purchases. The goal is to identify purchasing patterns, customer preferences, spending trends, and subscription behavior to help businesses make data-driven decisions.

## 🎯 Business Objective
To understand customer shopping behavior and discover opportunities to:
- Increase sales and revenue.
- Improve customer satisfaction.
- Strengthen customer loyalty.
- Optimize marketing strategies.
- Improve product positioning and discount policies.

## 🛠️ Tools & Technologies
- **Python:** Data Cleaning and Exploratory Data Analysis
- **Pandas:** Data Manipulation
- **Jupyter Notebook:** Data Analysis
- **PostgreSQL:** SQL Queries and Business Analysis
- **Power BI:** Interactive Dashboard
- **GitHub:** Project Documentation and Version Control

## 📊 Dataset Overview
- Total Records: 3,900
- Total Columns: 18
- Missing Values: 37 (Review Rating column)

### Key Features
- Customer Demographics
- Product Categories
- Purchase Amount
- Subscription Status
- Discount and Promo Code Usage
- Review Ratings
- Shipping Preferences
- Previous Purchases
- Shopping Frequency

## 🔍 Project Workflow

### 1. Data Cleaning & Exploratory Data Analysis (Python)
- Loaded and explored the dataset using Pandas.
- Checked data types and statistical summaries.
- Handled missing review ratings using category-wise median values.
- Standardized column names using snake_case.
- Created customer age groups.
- Engineered purchase frequency features.
- Connected Python with PostgreSQL.

### 2. SQL Business Analysis (PostgreSQL)

Performed 10 business analyses:

1. Revenue generated by male vs. female customers.
2. High-spending customers who used discounts.
3. Top 5 products based on average review ratings.
4. Average purchase amount by shipping type.
5. Subscribers vs. non-subscribers spending analysis.
6. Products with the highest discount purchase percentage.
7. Customer segmentation (New, Returning, Loyal).
8. Top 3 most purchased products in each category.
9. Repeat buyers and subscription analysis.
10. Revenue contribution by age group.

### 3. Power BI Dashboard
Developed an interactive dashboard to visualize:
- Customer purchasing trends.
- Revenue by gender.
- Product ratings.
- Shipping preferences.
- Subscription behavior.
- Customer segmentation.
- Business performance insights.

### 4. Business Recommendations
- **Boost Subscriptions:** Promote exclusive subscription benefits.
- **Customer Loyalty:** Reward repeat buyers to improve retention.
- **Discount Optimization:** Balance discount strategies with profitability.
- **Product Positioning:** Highlight top-rated and popular products.
- **Targeted Marketing:** Focus on high-revenue customer segments and express-shipping users.
